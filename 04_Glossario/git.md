# git

Un programma che ricorda ogni versione di ogni file di una cartella. Lo ha scritto Linus Torvalds nel 2005. Nel corso non lo usiamo mai direttamente: lo usa per noi **GitHub Desktop**. GitHub è il sito dove le cartelle gestite da git vengono conservate e condivise.
