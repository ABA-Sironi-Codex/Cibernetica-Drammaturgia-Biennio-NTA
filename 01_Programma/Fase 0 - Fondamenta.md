# Fase 0 · Fondamenta

**Domanda:** dove vive il mio lavoro?

Prima di scrivere per la scena digitale bisogna sapere dove stanno le cose: che cos'è un file, dove si trova, come si chiama davvero, come lo si mette al sicuro.

In questa fase parte anche la **raccolta dati**, nella sua versione più semplice: carta e penna. Vedi [Protocollo di raccolta](../06_Progetto-finale/Protocollo%20di%20raccolta.md).

## Alla fine di questa fase sai
- trovare qualunque file sul tuo computer e dire il suo [Percorso](../04_Glossario/Percorso.md)
- distinguere un file di [Testo semplice](../04_Glossario/Testo%20semplice.md) da un documento Word
- aprire un [Terminale](../04_Glossario/Terminale.md), muoverti tra le cartelle, installare un programma con un [Gestore di pacchetti](../04_Glossario/Gestore%20di%20pacchetti.md)
- proteggere un account con l'[Autenticazione a due fattori](../04_Glossario/Autenticazione%20a%20due%20fattori.md)
- creare il tuo Quaderno e aprirlo in Obsidian
- salvare il tuo lavoro su GitHub con il [rito di chiusura](../03_Guide/Guida%20-%20Rito%20di%20chiusura.md)
