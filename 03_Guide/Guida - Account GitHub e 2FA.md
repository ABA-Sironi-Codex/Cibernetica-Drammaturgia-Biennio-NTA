# Account GitHub e 2FA

GitHub è il posto dove il tuo Quaderno viene salvato e reso visibile. Per scriverci serve l'**autenticazione a due fattori** (2FA): oltre alla password, un codice che cambia ogni 30 secondi sul tuo telefono.

## Passi
1. Crea l'account su github.com. Scegli un nome utente che ti vada bene anche tra dieci anni: sarà il tuo portfolio
2. Installa sul telefono **Ente Auth** (https://ente.com/auth/): gratuita, open source, funziona su iPhone, Android e computer. Vedi [Software del corso](Software%20del%20corso.md)
3. Se vuoi, crea un account Ente: i tuoi codici avranno un backup cifrato e li ritroverai anche cambiando telefono
4. Su GitHub: **Settings → Password and authentication → Two-factor authentication**
5. Inquadra il QR code con Ente Auth

> [!CAUTION]
> **I codici di recupero**
> GitHub ti mostra dei **codici di recupero**. Se perdi il telefono sono l'unico modo per rientrare nel tuo account. **Scrivili su carta** e conservali. Non solo sul telefono.
