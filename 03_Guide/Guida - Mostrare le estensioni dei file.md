# Mostrare le estensioni dei file

Mac e Windows nascondono la parte finale del nome dei file, quella dopo il punto: l'[Estensione](../04_Glossario/Estensione.md). Per questo corso deve essere sempre visibile.

## Mac
1. Apri il **Finder**
2. Menu **Finder → Impostazioni** (sui sistemi più vecchi: *Preferenze*)
3. Scheda **Avanzate**
4. Spunta **Mostra tutte le estensioni dei file**

## Windows 11
1. Apri **Esplora file**
2. Menu **Visualizza → Mostra**
3. Spunta **Estensioni nomi file**

## Windows 10
1. Apri **Esplora file**
2. Scheda **Visualizza**
3. Spunta **Estensioni nomi file**
